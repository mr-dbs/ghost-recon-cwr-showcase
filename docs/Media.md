# Showcase media

Captured on stock Steam CW:R3.03 with the unchanged r002 addon, in Montignac on Everon. Temporary scene actors were positioned and their native animation states selected for the captures. No addon/engine/gameplay files were changed.

- town-banner.jpg: US and Russian GR characters plus the stock BIS Officer in town.
- officer-jacobs.jpg: default BIS WEST Officer (left), Will Jacobs with native GR OICW (right).
- idles.gif: EAST ready pose and three WEST combat-idle variants, about5.34seconds.
- russian-sprint.gif: native EAST low-carry sprint with actual world motion and a tracking camera, about3.68seconds.
- social-preview.jpg:1280x640 JPEG, under1MB, for GitHub's social preview setting.

Frames were captured at reduced simulation speed and exported using measured simulation elapsed time to preserve the animation's playback pace. GIF color reduction and image resizing are applied for page loading size. All soldiers, weapons, environments and motion are native captures, not AI-generated promotional art.

## Set the link thumbnail

Repository Settings -> General -> Social preview -> Edit -> Upload an image. Select docs/media/social-preview.jpg. The social preview setting is separate from the README banner; committing an image to the README does not configure the link thumbnail. Other devices/services may cache the old preview.

GitHub documentation: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview
